# DynamicProgramming
Code simuliert ein Spiel, bei dem zwei Spieler abwechselnd Schüsseln auswählen, um ihre Punktzahlen zu maximieren. Das Spiel heißt "Row of Bowls". Die maximal erreichbare Punktzahl wird durch Dynamic Programming ermittelt.

Dies wurde im SoSe2026 im Modul Algorithmen und Datenstrukturen erstellt.
